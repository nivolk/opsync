# Очередь

1. **Проверить установку у коллеги** по README буквально, с чужим OpenProject.
2. **Личный календарь в планировщике.** Рабочие часы и отсутствия пользователя есть в API
   (`/users/{id}/working_hours`, `/users/{id}/non_working_times`) — учитывать вместо одного
   `hours_per_day`.
3. **Связь плана с локальным трекером.** Поле элемента плана `ref: <id в трекере>`,
   `opsync find <ref>`.
4. **Codex и Cursor вживую.** Скилл ставится в `~/.agents/skills` (по их документации);
   проверить, что оба его подхватывают.
