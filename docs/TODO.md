# Очередь

1. **Проверить установку у коллеги** по README буквально, с чужим OpenProject.
2. **Личный календарь в планировщике.** Рабочие часы и отсутствия пользователя есть в API
   (`/users/{id}/working_hours`, `/users/{id}/non_working_times`) — учитывать вместо одного
   `hours_per_day`.
3. **Связь плана с локальным трекером.** Сейчас — конвенция `(OP #N)` в трекере (скилл,
   блок правил). Дальше: поле элемента плана `ref: <id в трекере>`, `opsync find <ref>`.
4. **Codex и Cursor вживую.** Скилл ставится в `~/.agents/skills` (по их документации);
   проверить, что оба его подхватывают и следуют блоку в AGENTS.md.
5. **Хуки в Claude Code вживую** — неделю работы: не мешают ли подсказки после коммита,
   хватает ли сводки при старте, пишет ли агент note в конце сессии.
6. **Отчёт по расписанию.** `opsync report --publish` раз в неделю (cron или routine), с
   «Главным» от агента — после того, как формат отчёта устоится.
